- Chrome: pointer-рисование по fixture данных 2.0.1, помощь и перезагрузка,
  скрытие ответа и контура, сохранность legacy, технические пропуски,
  ошибка записи, импорт/экспорт, мобильный 390px и desktop 1280px без overflow.

- Отдельная проверка PWA: прогрев → offline → reload → продолжение незавершённого

- Дополнительно: закрытие вкладки и новая вкладка; помощь → пропуск → новый

## Ограничения

Реальный iPhone/Apple Pencil, перенос навыка на бумагу и live Supabase не
проверялись. Серверная миграция подготовлена, но не применена на действующем
сайте. Пока она не развёрнута, расписание локальное и доступна копия файлом.
Тест offline использовал прогретые данные, не обещает наличие всех 1200 знаков
без предварительной загрузки. Автоматической загрузки чужой истории при смене
аккаунта нет. При долге от 20 карточек новые автоматически не добавляются; доступен явный
отдельный блок новых в пределах дневного лимита.
