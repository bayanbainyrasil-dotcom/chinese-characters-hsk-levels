# Отчёт Агента 13 — Специалист по совместимости и миграции данных (Compatibility & Data Migration Specialist)

## 1. Роль и цель
**Роль:** Ведущий инженер по миграциям баз данных, схемам хранения и целостности пользовательских данных.  
**Цель:** Проверить надёжность перехода от старых форматов хранения к новым без потери результатов пользователя, гарантировать автоматическое создание резервных копий перед первой модификацией, протестировать устойчивость к повреждённым данным и обрывам записи, обеспечить идемпотентность повторных миграций и полную обратную совместимость со старыми версиями сайта.

---

## 2. Архитектура хранения и стратегия миграции

Система использует двухуровневую архитектуру хранения:
1. **Оперативное локальное хранилище (`localStorage`):**
   - Ключ прогресса: `bishun_hsk30_progress_v1` (боевой неизменный ключ).
   - Ключ резервной копии: `bishun_hsk30_progress_backup_v1`.
   - Ключ маркера миграции: `bishun_hsk30_migration_v2`.
   - Защита: обёртка `storage.js` с резервной памятью `memoryFallback` на случай блокировки `localStorage` (Safari Private Browsing, переполнение квоты).
2. **Транзакционное хранилище расписания памяти (`IndexedDB`):**
   - База: `bishun-writing-memory-v1`.
   - Хранилища объектов: `events` (keyPath: `id`), `meta`.
   - Атомарность: транзакции `readwrite` с автоматическим `abort()` и откатом при ошибках валидации.

## 4. Защита от потери данных в приватных режимах и при сбоях
1. **Safari Private Browsing / QuotaExceededError:**
   - Если браузер запрещает запись в `localStorage` (квота или приватный режим), метод `writeRaw` перенаправляет запись в `memoryFallback` (in-memory Map).
   - Пользователь продолжает занятие без белого экрана и без потери сессии.
2. **Экспорт и импорт в UI (DEF-04):**
   - Кнопки экспорта и импорта вынесены на экран прогресса (`progressView`) и доступны всегда в один клик.
