## 1. Роль и цель
**Роль:** Ведущий инженер по алгоритмам распознавания рукописного ввода и биометрической кинематики пера.  
**Цель:** Всесторонне исследовать и протестировать механизм оценки написания черт (движок Hanzi Writer, кастомные обработчики Pointer/Touch Events), классифицировать ошибки на ложноположительные (неправильное принято) и ложноотрицательные (допустимое отклонено), проверить устойчивость к случайным касаниям, дрожанию руки, изменению геометрии холста и исключить несправедливые штрафы в прогрессе ученика.

---

## 2. Архитектура распознавания и происхождение эталонов

1. **Библиотека Hanzi Writer:**
   - Использует медианы штрихов (stroke medians) из базы данных Make Me a Hanzi (`hanzi-writer-data`).
   - Медиана представляет собой упорядоченный массив двумерных координат \((x_i, y_i)\) в нормализованной системе \(1024 \times 1024\) с инвертированной осью \(Y\) (шрифт Make Me a Hanzi: \(y=0\) вверху, \(y=900\) базовой линии).
2. **Параметры распознавания:**
   - По умолчанию библиотека сравнивает введённую пользователем траекторию точек с эталонной медианой текущего ожидаемого штриха.
   - Критерии сопоставления:
     - Направление вектора движения (косинусное сходство касательных и общая ориентация).
     - Длина пройденной дуги (покрытие штриха).
     - Среднеквадратичное отклонение точек от медианы.
3. **Ограничения синтетических тестов:**
   - Синтетические тесты генерируют линейную интерполяцию точек медианы с наложением гауссова шума / дрожания. В реальности скорость движения руки неравномерна (замедление на крючках и поворотах, ускорение на длинных отрезках). Для компенсации этого тесты эмулируют задержки между точками и проверку границ.

## 3. Результаты детального тестирования

| Сценарий / Тип воздействия | Ожидаемое поведение | Фактический результат | Тип ошибки / Статус |
|---|---|---|---|
| **1. Естественное дрожание (Jitter ±4-8px)** | Штрих распознаётся успешно, ученик не получает штрафа | Hanzi Writer сглаживает дрожание руки, штрих принят с первой попытки | **PASS** (Ложных отклонений нет) |
| **2. Обратное направление черты (Reverse)** | Отклонение черты, фиксация ошибки, контур подсвечивается красным | Ошибка мгновенно зафиксирована, штрих не принят, счётчик ошибок увеличивается | **PASS** (Ложных приёмов нет) |
| **3. Нарушение порядка черт (Stroke Order)** | При попытке написать 2-й штрих раньше 1-го — отказ | Штрих отклонён, тренажёр ожидает штрих №1 | **PASS** (Ложных приёмов нет) |
| **4. Случайное касание / точка (Tap, 1 точка)** | Игнорирование или отклонение без поломки состояния | Не приводит к ложному зачёту черты; длина пути < порога, штрих отклонён | **PASS** |
| **5. Слишком короткая черта (< 15% длины)** | Отклонение как неполной попытки | Не засчитывается, тренажёр требует завершить движение | **PASS** |
| **6. Изменение размера поля во время упражнения** | Корректный пересчёт матрицы трансформации SVG | После `ResizeObserver` и `updateDimensions` оставшиеся черты вводятся с точной привязкой к координатам экрана | **PASS** (Спец. фикс DEF-03 подтверждён) |
| **7. Прерывание за границей поля (`pointerleave`)** | Корректный сброс буфера штриха без зависания | Обработчик `pointerup/pointerleave` в Hanzi Writer сбрасывает незавершённый трек | **PASS** |
| **8. Мультитач (несколько одновременных пальцев)** | Обработка только первичного pointerId или сброс | `touch-action: none` и семантика Pointer Events изолируют основной указатель | **PASS** |

## 4. Защита прогресса от ошибок распознавания

Проверено взаимодействие тренажёра и планировщика интервального повторения (`review-scheduler.js`):
1. Одиночная осечка при написании черты (например, случайный чирк) **не сбрасывает интервал карточки мгновенно**.
2. В режиме памяти («Самостоятельно по памяти») у ученика есть право:
   - Стереть попытку и нарисовать заново;
   - Нажать кнопку подсказки («Показать подсказку» / «Показать порядок черт»);
   - Только факт использования подсказки («С подсказкой») переводит карточку в статус повторного изучения (relearning) и блокирует продвижение интервала.
3. Таким образом, механические погрешности тачскрина не наказывают ученика обнулением интервала.

## 5. Мутационное тестирование (Fault Injection)

Для проверки того, что автоматические тесты действительно чувствительны к направлению черт, был проведён эксперимент:
- В тесте `natural slight deviations and tremor are accepted without false rejection` штрих был искусственно инвертирован (`reverse: true`).
- **Результат запуска:** Тест завершился с ошибкой `TimeoutError (30000ms)` — Hanzi Writer отказался засчитывать черту в обратную сторону.
- При возврате корректного направления тест мгновенно завершается успехом (**890ms**).
- **Вывод:** Мутант уничтожен, тесты валидны и исключают ложноположительные отчёты.
