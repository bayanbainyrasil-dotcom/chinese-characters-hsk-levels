# Отчёт Агента 3 — Возвращающийся ученик (Returning Learner)

## 1. Роль и цель
**Роль:** Ученик, который занимался на сайте некоторое время назад, накопил историю, забыл часть знаков и вернулся для продолжения занятий.  
**Цель:** Проверить восстановление незавершённой сессии, работу очереди интервального повторения при накопившемся бэклоге, поведение при забывании и понятность статистики.

## 2. Результаты проверок

### Сценарий 3.1: Восстановление прерванного занятия после перезагрузки
- **Ожидаемое поведение:** Если пользователь закрыл вкладку посреди упражнения, при повторном открытии сайта он видит карточку продолжения.
- **Фактическое поведение:** На главной странице появляется карточка `continueCard` с названием прерванного урока, а в модуле тренировки памяти — кнопка `memoryResume` («Продолжить»).
- **Статус:** **PASS**
- **Доказательство:** `tests/e2e.test.mjs` (тест 81: «продолжение занятия видно на главной»), `tests/review-e2e.test.mjs` (тест 40).

### Сценарий 3.2: Забывание знака и повторное обучение
- **Ожидаемое поведение:** Если ученик нажал «Не помню» или запросил подсказку с образцом, знак переходит в режим отработки `practice`, а интервал не увеличивается ложно.
- **Фактическое поведение:** Знак помечается как `assisted: true`, кнопка «Вспомнил сам» блокируется, знак переводится в фазу переобучения (`relearning`) и планируется к повторной проверке после промежуточных знаков.
- **Статус:** **PASS**
- **Доказательство:** `tests/review-scheduler.test.mjs` (тесты 10, 15, 18), `tests/mnemonic-e2e.test.mjs` (тест 20).

### Сценарий 3.3: Дневной лимит новых знаков при большом бэклоге
- **Ожидаемое поведение:** Приоритет отдаётся повторению ранее изученного (due reviews), новые знаки вводятся строго порциями (по умолчанию 5 знаков в день).
- **Фактическое поведение:** Функция `planQueue` сначала отбирает элементы из `due`, пока они не будут отработаны, предотвращая перегрузку ученика лавиной новых символов.
- **Статус:** **PASS**
- **Доказательство:** `tests/review-scheduler.test.mjs` (тесты 14, 17).
