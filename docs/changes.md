### Lighthouse

| | Производительность | Доступность | Практики | SEO |
|---|---|---|---|---|
| мобильный | **99** | **100** | **100** | **100** |
| десктоп | 77 | **100** | **100** | **100** |

Десктопная цифра занижена условиями замера: локальный сервер отдаёт файлы
по HTTP/1.1 без сжатия, а десктопный профиль Lighthouse добавляет задержку
сети на каждый запрос. GitHub Pages отдаёт то же самое по HTTP/2 с gzip.
Оставшиеся замечания — только про минификацию и заголовки кэша, то есть про
то, чем распоряжается хостинг.
