# Аудиопак

Здесь лежат заранее подготовленные записи произношения: `n/` — обычная скорость,
`s/` — медленная. Имя файла — hex-представление слова в UTF-8, поэтому оно
одинаково считается и в браузере (`js/audio.js`), и в генераторе.

Сгенерировать или дополнить пак:

```bash
node tools/generate-audio.mjs --engine edge --limit 0
```

`manifest.json` перечисляет готовые идентификаторы: сайт заглядывает в него,
прежде чем идти на сервер озвучки.
