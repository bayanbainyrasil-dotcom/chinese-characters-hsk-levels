# Chinese Characters · HSK Levels

Тренажёр письма китайских иероглифов по официальному стандарту HSK 3.0.
Живёт на GitHub Pages: <https://bayanbainyrasil-dotcom.github.io/chinese-characters-hsk-levels/>

* 1 200 письменных знаков и 11 000 официальных слов с русскими переводами;
* четыре раздела: восемь базовых черт → порядок черт → 50 ключей → письмо по HSK;
* знак считается изученным после пяти правильных написаний;
* письмо пальцем, Apple Pencil и мышкой с проверкой каждой черты (Hanzi Writer);
* озвучка путунхуа, разбор слов по знакам, синхронизация между устройствами;
* работает офлайн, ставится как приложение (PWA).

## Как всё устроено

Обычные HTML, CSS и JavaScript без сборки. Модули лежат в `js/`, данные —
в `data/`, необязательный бэкенд — в `supabase/`.

| Слой | Где | Что делает |
|---|---|---|
| Обучение | `app.js` | разделы, занятие, письмо, поиск, админка |
| Хранение | `js/storage.js`, `js/progress.js` | localStorage, слияние, миграция |
| Синхронизация | `js/sync.js` | вход, очередь событий, индикатор |
| Озвучка | `js/audio.js` | статический пак → сервер → голос браузера |
| Разбор слов | `js/pinyin.js`, `js/dictionary.js`, `js/wordcard.js` | слоги, значения, карточка |
| Анимации | `js/motion.js` | появления, счётчики, `prefers-reduced-motion` |

### Local-first

Результат написания сразу ложится в localStorage, интерфейс не ждёт сервер.
Событие с собственным UUID уходит в очередь и отправляется в фоне — при входе,
возвращении на вкладку, восстановлении сети и после упражнения. Повторная
отправка ничего не задваивает: идентификатор события является первичным ключом.

Без интернета и без аккаунта сайт работает полностью — просто прогресс
остаётся на устройстве.

### Данные разбора

Чтение каждого знака берётся не из общего пиньиня слова, а из разбиения
официального пиньиня по слогам: число слогов заранее известно (равно числу
иероглифов), а правило орфографии про апостроф перед `a`/`e`/`o` снимает
оставшуюся неоднозначность. На всех 10 896 словах разбиение однозначно;
результат JS и Python сверяется автотестом.

Значения знаков собраны из официального списка HSK, письменного минимума и
переводов словарных статей; источник каждого значения помечен в
`data/characters.json` полем `s`.

## Запуск локально

```bash
python3 -m http.server 8000
# http://localhost:8000
```

Открывать именно по `http://` — модули ES и Service Worker не работают
из файла.

## Тесты

```bash
npm install
npm test              # 47 проверок: модульные, сквозные, озвучка
npm run lighthouse    # производительность, доступность, SEO
```

Схема базы проверяется отдельно, на локальном PostgreSQL:

```bash
createdb hsktest
psql -d hsktest -f tests/sql/stub.sql
psql -d hsktest -f supabase/migrations/0001_init.sql
psql -d hsktest -f tests/sql/check.sql
```

## Обслуживание

```bash
npm run data     # пересобрать data/characters.json
npm run audio    # собрать аудиопак (нужен pip install edge-tts)
npm run bump     # поднять версию кэша перед публикацией
```
